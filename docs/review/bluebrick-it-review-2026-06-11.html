Architecture Map

The current system is local-first, review-first, and policy-gated before expanding into mutation or external integration.

WinForms PanelAssistantPanel.cs. User-facing assistant, status, screenshot, and tool-result surface.
Local BridgeAgentHttpServer. HTTP boundary with auth, route handling, and SSE serialization.
Assistant RuntimeOpenAiAssistantService. Model selection, streaming, tool calling, redaction.
Tool PolicyAssistantToolService and policy classes. Allows read/search, denies risky routes by default.
Relay And SystemsRelay, Vault, PDM, Epicor, Salesforce, documents. Integrated only behind reviewed contracts.

Security Posture

WebView2

Host objects disabled, unexpected navigation blocked, popups blocked, token text scanned in shell HTML.

Tool Policy
