# Font Files

This directory should contain the following TTF font files:

## Space Grotesk

Download from: https://fonts.google.com/specimen/Space+Grotesk

- SpaceGrotesk-Regular.ttf
- SpaceGrotesk-Bold.ttf

## IBM Plex Sans

Download from: https://fonts.google.com/specimen/IBM+Plex+Sans

- IBMPlexSans-Regular.ttf
- IBMPlexSans-Bold.ttf

## Installation Instructions

1. Visit the Google Fonts links above
2. Click "Download family" button
3. Extract the ZIP file
4. Copy the `*-Regular.ttf` and `*-Bold.ttf` files to this directory
5. Rebuild the project

The application will fall back to Segoe UI if these fonts are not found.
